## 三、本轮发现的两个核心问题

### 问题 A：管理后台短剧编辑弹窗未接 VOD（已修）

**症状**：
[`未来管理系统/frontend/src/views/DramaManage.vue`](../frontend/src/views/DramaManage.vue) 列表页「修改」弹窗的「文件」字段是占位 `<el-upload>`，提交时只弹「文件上传至阿里云 VOD 尚未接入」提示，根本没调 VOD。

仓库里同时存在 [`未来管理系统/frontend/src/views/DramaForm.vue`](../frontend/src/views/DramaForm.vue) 这个孤儿页面（路由有 `/dramas/edit/:id`，但侧栏菜单没入口），里面接了真上传的 `VodUploader`。

**修复**：

1. 新建 [`未来管理系统/frontend/src/components/VodBatchUploader.vue`](../frontend/src/components/VodBatchUploader.vue)（578 行）：
   - 多文件 `<el-upload multiple>` 一次选 N 个
   - 内部 `tasks` 数组管理每个文件状态
   - 并发 2 路上传（每文件内部 SDK 仍 3 part 并行）
   - 文件名按 `localeCompare(zh, numeric)` 排序自动分配 `episode_num`
   - 上传中绑定 `beforeunload` 防误关
2. [`未来管理系统/frontend/src/views/DramaManage.vue`](../frontend/src/views/DramaManage.vue) 主弹窗内一行：

```vue
<el-form-item label="视频文件">
  <VodBatchUploader v-model="formData.episodes" :drama-title="formData.name" />
</el-form-item>
```

3. 删除孤儿 `DramaForm.vue` + 移除 `router/index.js` 第 16-17 行两条路由 + 清理 `Layout.vue` 三处 `/dramas/edit` 残留

### 问题 B：阿里云 VOD `UploadSucc` 状态被泄漏 → 5 集卡死（已修）

**症状**：用户上传 10 集，5 集自动到 `normal`、5 集卡在英文 `uploadsucc`，状态再也不会推进；实际阿里云那边早已 `Normal`。

**根因链**：

```mermaid
flowchart LR
  Aliyun["阿里云返回 UploadSucc"] --> norm["VodService.normalizeStatus 不识别"]
  norm --> raw["返回原值 uploadsucc"]
  raw --> db["数据库 vod_status='uploadsucc'"]
  db --> task["DramaEpisodeVodSyncTask 只捞 uploading/transcoding"]
  task --> dead["uploadsucc 永远不被刷新 → 卡死"]
```

**修复**：

1. [`未来管理系统/backend-java/src/main/java/com/drama/service/VodService.java`](../backend-java/src/main/java/com/drama/service/VodService.java) `normalizeStatus()` 第 257-263 行加入 `uploadsucc/uploadsuccess/checking/reviewing → transcoding` + `deleted → failed` 映射
2. [`未来管理系统/backend-java/src/main/java/com/drama/task/DramaEpisodeVodSyncTask.java`](../backend-java/src/main/java/com/drama/task/DramaEpisodeVodSyncTask.java) 第 33-34 行 `selectByVodStatuses(...)` 清单兜底加入 `uploadsucc/checking/reviewing`，应对历史脏数据
3. [`未来管理系统/frontend/src/components/VodBatchUploader.vue`](../frontend/src/components/VodBatchUploader.vue) `statusText` map + `mapVodStatus` 都加中文兜底，防御未来再有未识别状态
4. **零 SQL 迁移**：因为修复 2 让轮询自动接管，下一次 60s 周期就把 5 条推进到 `normal`（验证通过）

# VOD 事件回调接入设计 · 2026-04-20

## 背景

当前 [`未来管理系统/backend-java/src/main/java/com/drama/task/DramaEpisodeVodSyncTask.java`](../backend-java/src/main/java/com/drama/task/DramaEpisodeVodSyncTask.java) 是 60s 轮询模式：每分钟从 `drama_episodes` 捞一批 `vod_status IN (uploading, transcoding, uploadsucc, checking, reviewing)` 的行，逐个调阿里云 `GetVideoInfo` 看状态，再 `UPDATE` 回数据库。

缺点：
- **延迟高**：阿里云上传/转码完成 → 平均 30s 后本地数据库才更新
- **API 调用浪费**：每分钟轮询 N 个视频 = N 次 `GetVideoInfo`，按量计费会持续累计
- **服务器空跑**：大部分时刻 N=0，但调度器还在运行

## 设计目标

将状态变更从**拉**改为**推**：阿里云 VOD 触发事件 → 公网回调到我们的 ECS → 后端实时更新 `vod_status` + 短剧聚合 `task_status`。

## 三、需要的改动概览

| 项 | 改动 |
|---|---|
| 阿里云控制台 | 在 VOD 配置 → 消息通知里设置回调 URL `https://admin.hookedshorts.com/api/vod/callback`，订阅以下事件：`UploadByURLComplete`、`FileUploadComplete`、`StreamTranscodeComplete`、`TranscodeComplete`、`SnapshotComplete` |
| 后端新增 endpoint | `POST /api/vod/callback`（开 Spring Security 白名单 + 自有签名校验） |
| nginx | `admin.hookedshorts.com` 增加 `location = /api/vod/callback { ... }`；不限制源 IP（阿里云出网 IP 段太多），但只允许 POST + 强制 TLS |
| 后端工厂方法 | 复用现有 `VodService.normalizeStatus()` 把 `EventType` 映射成数据库 `vod_status` |
| 去重 | 同一 videoId 同一事件不重复处理（用 `event_id` 写入 `vod_callback_log` 表） |
| 回退 | 保留现有轮询任务，但把 `fixedDelay` 从 60s 调到 300s（兜底，应对回调失败） |

## 四、回调端点设计

### 4.1 路由 + 安全

```java
@RestController
@RequestMapping("/api/vod")
public class VodCallbackController {

    private final VodCallbackService callbackService;

    @PostMapping("/callback")
    public ResponseEntity<String> callback(@RequestBody Map<String, Object> body,
                                            HttpServletRequest req) {
        // 阿里云 VOD 回调签名校验（HMAC-SHA1）
        if (!callbackService.verifySignature(body, req)) {
            return ResponseEntity.status(401).body("invalid signature");
        }
        callbackService.handle(body);
        return ResponseEntity.ok("ok");
    }
}
```

`SecurityConfig` 开白：`/api/vod/callback` 不需要 JWT。

### 4.3 签名校验

阿里云 VOD 回调用 **HMAC-SHA1**，密钥是控制台「消息通知」里设置的回调密钥（建议存到 `/data/env/drama-admin.env`：`ALIYUN_VOD_CALLBACK_SECRET=...`）。

```java
boolean verifySignature(Map<String, Object> body, HttpServletRequest req) {
    String received = String.valueOf(body.remove("Checksum"));
    String secret = env.getProperty("aliyun.vod.callback-secret");
    String canonical = canonicalize(body);  // key 排序后用 \n 拼接
    String calc = HmacUtil.sha1Hex(canonical, secret);
    return MessageDigest.isEqual(received.getBytes(), calc.getBytes());
}
```

### 4.4 处理逻辑

```java
public void handle(Map<String, Object> body) {
    String eventId = String.valueOf(body.get("Sequence")) + "_" + body.get("VideoId") + "_" + body.get("EventType");

    // 去重：同一事件 30 分钟内只处理一次
    if (callbackLogMapper.existsByEventId(eventId, Duration.ofMinutes(30))) {
        return;
    }
    callbackLogMapper.insert(toLogRow(body, eventId));

    String videoId = String.valueOf(body.get("VideoId"));
    String rawStatus = String.valueOf(body.get("Status"));
    String normalized = vodService.normalizeStatus(rawStatus);

    DramaEpisode row = dramaEpisodeMapper.selectByVodVideoId(videoId);
    if (row == null) return;  // 视频不在我们管理范围

    row.setVodStatus(normalized);
    if (body.get("Duration") != null) row.setDuration(toInt(body.get("Duration")));
    if (body.get("Size") != null) row.setVideoSize(toLong(body.get("Size")));
    if (body.get("CoverUrl") != null) row.setVodCoverUrl(String.valueOf(body.get("CoverUrl")));
    row.setUpdatedAt(LocalDateTime.now());
    dramaEpisodeMapper.updateById(row);

    // 触发短剧聚合 task_status 重算
    dramaService.refreshTaskStatus(row.getDramaId());
}
```

### 4.5 新增表 `vod_callback_log`

```sql
CREATE TABLE vod_callback_log (
  id           BIGINT PRIMARY KEY AUTO_INCREMENT,
  event_id     VARCHAR(128) NOT NULL,
  video_id     VARCHAR(64)  NOT NULL,
  event_type   VARCHAR(64)  NOT NULL,
  raw_status   VARCHAR(32),
  payload      TEXT,
  received_at  DATETIME DEFAULT CURRENT_TIMESTAMP,
  UNIQUE KEY uk_event_id (event_id),
  INDEX idx_video_id (video_id),
  INDEX idx_received_at (received_at)
);
```

存 7 天，定期归档（避免无限增长）。

## 五、与现有轮询任务的关系

| 场景 | 谁负责 |
|---|---|
| 阿里云事件正常推送（99%+ 情况） | 回调 |
| 回调网络异常 / nginx 宕机 / 后端短暂 5xx | 5 分钟兜底轮询 |
| 历史脏数据（uploadsucc/checking/...）残留 | 兜底轮询第一轮就接管 |
| 阿里云 5min 内重复推送（常见） | `vod_callback_log` 去重 |
